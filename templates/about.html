About This Project

What is AI Resume Analyzer?

AI Resume Analyzer is an intelligent web application that helps job seekers understand how well their resume matches specific job roles using machine learning and natural language processing techniques.

How It Works

  1. Resume Parsing: Uses NLP to extract skills, education, experience, and contact information from PDF/DOCX files.
  2. TF-IDF Vectorization: Converts resume text and job descriptions into numerical vectors.
  3. Cosine Similarity: Measures the similarity between resume and job description vectors (0-100%).
  4. Skill Gap Analysis: Identifies missing required and preferred skills.
  5. Scoring Algorithm: Combines TF-IDF similarity (40%), required skills match (45%), and preferred skills match (15%).
